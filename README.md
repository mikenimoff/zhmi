# Жми

Локальная macOS-утилита для пакетного сжатия видео.

> Привет, это Майк. Это полностью бесплатное приложение для сжатия ваших видеофайлов. Никогда и никому не позволяйте убедить вас в обратном.
>
> [nimoff.app](https://nimoff.app/)

## Запуск

### Готовая сборка

Скачайте последнюю версию на странице [Releases](https://github.com/mikenimoff/zhmi/releases). Приложение предназначено для Mac с Apple Silicon и macOS 15 или новее.

Перед запуском установите `ffmpeg`:

```bash
brew install ffmpeg
```

### Нативное приложение

Собрать `.app`:

```bash
./build_app.sh
```

Открыть приложение:

```bash
open build/Жми.app
```

### Запасной веб-интерфейс

Дважды нажмите `Жми.command` или запустите:

```bash
python3 app.py
```

После запуска откроется:

```text
http://127.0.0.1:8766/
```

## Возможности

- выбор папки с видеофайлами;
- выбор одного видеофайла;
- выбор сразу нескольких папок одной задачей;
- выбор папки для готовых файлов;
- пакетная обработка `.mp4`, `.mov`, `.m4v`, `.avi`, `.mkv`, `.webm`;
- рекурсивное сохранение структуры выбранных папок: видео сжимаются, остальные файлы копируются без изменений;
- исходные имена сохраняются при выводе в другую папку; суффикс `_compressed` используется при выводе рядом с исходником;
- разрешение: оригинал, 2560x1440, 1920x1080, 1280x720;
- степень сжатия: легкая, сбалансированная, сильная, максимальная;
- общий прогресс, прогресс текущего файла и статус;
- индикатор общего прогресса на Dock-иконке, а также состояния завершения и ошибки;
- повторная постановка ошибочных файлов в конец активной очереди без остановки задачи;
- журнал восстановления с путями и статусами (без копирования исходников) и продолжение незавершённой задачи после перезапуска;
- сброс незавершённой задачи с сохранением исходных и уже готовых файлов;
- автоматическая и ручная проверка новых версий через GitHub Releases с уведомлением и ссылкой на скачивание;
- фирменный логотип в интерфейсе и как иконка приложения;
- остановка процесса;
- автоостановка с ошибкой, если `ffmpeg` перестал отдавать прогресс.

Приложение ожидает `ffmpeg` и `ffprobe` в `/opt/homebrew/bin/`.
